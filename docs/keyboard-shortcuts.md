# Keyboard shortcuts

⌘ on macOS, Ctrl elsewhere, unless noted.

## Anywhere

| Keys | Action |
|------|--------|
| Ctrl/⌘ + K | Command palette (rooms and actions; `>` for actions only) |
| Ctrl/⌘ + I | Mentions inbox |
| Ctrl/⌘ + F | Search the current room |
| Ctrl/⌘ + C | Copy selected text |
| Ctrl/⌘ + V | Paste an image from the clipboard as an attachment |
| Alt + 1–9 | Go to the Nth room in the room list |
| Alt + ↑ / ↓ | Previous / next room |
| Alt + Shift + ↑ / ↓ | Previous / next unread room |
| Esc | Close the topmost menu, dialog, panel or sidebar |

## Panes and windows (tmux-style)

Press **Ctrl+B**, then:

| Key | Action |
|-----|--------|
| `%` | Split side by side |
| `"` | Split stacked |
| `x` | Close pane |
| `z` | Zoom / restore pane |
| `o` | Next pane |
| ← → ↑ ↓ / `h` `l` `k` `j` | Move focus between panes |
| `c` | New window |
| `n` / `p` | Next / previous window |
| `0`–`9` | Go to window |
| `&` | Close window |
| `?` | Show these keys |

See [Panes and windows](panes-and-windows.md).

## In the message box

| Keys | Action |
|------|--------|
| Enter | Send (or Ctrl/⌘ + Enter, with the *Send with Ctrl+Enter* preference) |
| Shift + Enter | New line |
| Tab | Cycle command / mention completions; insert emoji suggestion |
| ↑ (empty box) | Edit your last message |
| PageUp / PageDown | Scroll the timeline |
| Ctrl + End | Jump to the newest message |
| Ctrl/⌘ + U | Clear the message box |

## In lists (palette, search)

| Keys | Action |
|------|--------|
| ↑ / ↓ | Move the selection |
| Enter | Open / run |
| Esc | Close |
