# fluxchat user manual

fluxchat is a native Matrix chat client with an IRC-inspired interface. This manual covers everything you can do in it.

## Start here

- [Getting started](getting-started.md): install, sign in, find your way around

## Using fluxchat

- [The interface](interface.md): spaces bar, room list, timeline, sidebars, status bar
- [Messaging](messaging.md): writing, formatting, mentions, replies, edits, reactions, files, polls
- [Threads](threads.md): reading and replying in threads
- [Panes and windows](panes-and-windows.md): split the screen tmux-style, multiple windows
- [Rooms and spaces](rooms-and-spaces.md): joining, creating, room settings, spaces, the directory
- [People](people.md): profiles, presence, roles, moderation, ignoring
- [Notifications and mentions](notifications.md): desktop alerts, rules, keywords, the mentions inbox
- [Voice and video](calls.md): calls, voice messages, devices
- [AI agents](agents.md): commands, runs, Stop / Steer / Queue and approvals for agents like Hermes
